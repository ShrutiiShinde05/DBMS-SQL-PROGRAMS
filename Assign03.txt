INNOVATION : Data Security using Privilege Control

In this assignment, different users were created and specific privileges were given to them. This helps in improving database security because each user can access only the data they are permitted to use. For example, user1 was allowed to SELECT data but not INSERT, which prevents unauthorized changes in the database.

Innovation 2: Biometric-Based Database Security
In the future, databases can use biometric authentication such as fingerprint or face recognition to allow access. This will improve database security because only authorized users will be able to log in and access sensitive data. 

Innovation 3: Create a View for Secure Data Access

Idea: Instead of giving access to the whole table, we can create a VIEW so users can see only required data.

Query
CREATE VIEW stud_view AS
SELECT name, marks FROM stud;

SELECT * FROM stud_view;
Explanation

This view hides the roll number and shows only name and marks, which improves data privacy and security.
